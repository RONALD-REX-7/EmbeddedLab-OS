## Reporting a Vulnerability

If you discover a potential security vulnerability within **EmbeddedLab OS**, please report it responsibly:

1. **Do not create a public issue**: Please do not open public GitHub issues or discussions for sensitive security bugs.
2. **Contact Privately**: Send details via GitHub Security Advisory (preferred) or email the maintainer directly at `211186833+RONALD-REX-7@users.noreply.github.com`.
3. **Include Details**: Provide a description of the vulnerability, reproduction steps or proof-of-concept, and expected vs observed impact.

We take security and safe virtualization seriously and will acknowledge receipt within 48 hours and work on remediation promptly.
